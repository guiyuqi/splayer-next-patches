# splayer-next-patches

**SPlayer-Next 的非官方修改版补丁集**（只有补丁，不含上游源码、不含任何二进制）。

- 维护者：guiyuqi（个人使用 / 学习用途）——**不是** SPlayer-Next 作者，也不是官方发布
- 基线：SPlayer-Next `dev` 分支提交 **`4c60335`**（2026-09-30）
- 许可：与上游一致，**AGPL-3.0**（见 [LICENSE](./LICENSE)）；第三方声明见 [NOTICE](./NOTICE)
- 逐条改动、**证据等级**与未验证点：见 [CHANGES.md](./CHANGES.md)

> ⚠️ 这些改动是在个人使用场景下、借助 AI 辅助完成的。CHANGES.md 里按 A/B/C/D 标注了每条改动的
> 证据强度，其中 **C 级属于推断、没有复现原始问题**，请不要把它当成"已修复的 bug"。

## 用法

```bash
git clone -b dev https://github.com/SPlayer-Dev/SPlayer-Next.git splayer-next
cd splayer-next
git checkout 4c60335

git am /path/to/splayer-next-patches/patches/*.patch   # 按编号顺序
pnpm install
pnpm dev                                               # 或 pnpm build:win
```

- **只挑一部分**：按编号顺序应用即可，但 **`0001` 是所有主题的公共前置**（共享类型 / 设置项定义 / 中英文案），必须最先应用。
- **依赖关系**：`0008`（播客）里的 4 个 MCP 工具注册代码位于 `0006` 的 `server.ts` 中，两个补丁一起用才完整；`0009`（宏音量 + 唤醒修复）**与 0001~0008 无重叠**，只依赖基线 `4c60335`；已验证能单独 `git am` 干净应用，但没有单独编译验证（完整系列已验证）。
- `components.d.ts` 是自动生成文件，**未包含在补丁里**：首次 `pnpm dev` 或构建会自动补齐。
